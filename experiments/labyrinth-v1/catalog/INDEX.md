# Expedition catalog — choose by environment

This catalog contains no recovery phrases. The mission's observation determines which environment archive to open.

- [The Ember Register](https://github.com/bonoj/Pit/blob/main/experiments/labyrinth-v1/regions/ember/INDEX.md): hot mineral vents, ashfall, furnaces, metallic ringing in dry air.
- [The Pelagic Register](https://github.com/bonoj/Pit/blob/main/experiments/labyrinth-v1/regions/pelagic/INDEX.md): open ocean, salt spray, submerged lights, tidal instruments.
- [The Cryosphere Register](https://github.com/bonoj/Pit/blob/main/experiments/labyrinth-v1/regions/cryo/INDEX.md): frozen lakes, glacial cavities, sub-ice acoustics, winter anomalies.
- [The Canopy Register](https://github.com/bonoj/Pit/blob/main/experiments/labyrinth-v1/regions/canopy/INDEX.md): rainforests, high branches, animal calls, wind through leaves.

Select the single best matching environment and continue. Do not stop at this catalog.
